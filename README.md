# langues-platform

Plateforme de cours de langues (hébreu, anglais, espagnol, français, roumain) : site public, CMS, réservation, visio, espace élève, vidéos et exercices, dashboards, facturation.

Les règles de développement sont dans [`CLAUDE.md`](CLAUDE.md).

## Stack

Next.js (App Router, TypeScript) · Payload CMS · Supabase · LiveKit · Bunny Stream · Mollie
